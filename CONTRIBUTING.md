# Contributing
Run `npm test` and `npm run build` before opening a pull request. Keep the interaction short and outdoor-focused. Never mislabel sample data as AI output. Do not commit credentials or personal journal exports.

Useful contributions:
- Add automated browser tests for completing quests and restoring timers.
- Add a validated journal backup import flow.
- Add accessible reduced-motion improvements and localization.
- Add optional authenticated cloud persistence with ownership checks.

Describe the problem, change and verification in your PR. Discuss large features in an issue first.
